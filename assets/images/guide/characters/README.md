Портреты для онлайн-путеводителя.

Файлы, указанные в поле «Портрет» файла assets/data/guide/entries.json, размещаются здесь: assets/images/guide/characters/

Названия файлов должны совпадать с указанными в JSON. Сейчас карточки автоматически показывают буквенную заглушку, если портрет ещё не загружен.
